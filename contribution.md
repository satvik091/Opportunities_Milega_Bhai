# 📘 CONTRIBUTING.md for *Opportunities_Milega_Bhai*

Thank you for your interest in contributing to **Opportunities Milega Bhai**! 🚀  
This repository is all about collecting and organizing the best resources to help students crack placements—from DSA and interview prep to resume building and company-wise preparation.

---

## 🙌 Ways You Can Contribute

✅ **Company-Based DSA**  
Add questions, solutions, or topic-wise resources to the [`Company_Based_Dsa`](https://github.com/satvik091/Opportunities_Milega_Bhai/tree/Company_Based_Dsa) folder.  
Organize them clearly like this:
```
Company_Based_Dsa/
├── Amazon/
│   ├── questions.md
│   └── solutions/
│       └── problem1.cpp
├── Google/
│   └── ...
```

✅ **Interview Experiences**  
Create a folder or markdown file with your experience. Use this structure:
```
Interview_Experiences/
├── Company_Name/
│   └── YourName_or_Anonymous.md
```

✅ **Aptitude / CS Fundamentals**  
Add PDF links, question sets, formulas, or cheat sheets:
```
Aptitude/
CS_Fundamentals/
```

✅ **Resume / LinkedIn Tips**  
Drop resume templates, best practices, and links to helpful videos/blogs in:
```
Resume_LinkedIn_Tips/
```

✅ **Add External Resources**  
If you know of amazing YouTube playlists, GitHub repos, or blogs, include them under:
```
Resources/
└── External_Links.md
```

## 📄 How to Contribute (Step-by-Step)
1. **Fork** the repository.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/YOUR-USERNAME/Opportunities_Milega_Bhai.git
   ```
3. **Create a new branch** for your changes:
   ```bash
   git checkout -b feature/resource-name
   ```
4. **Make your changes**, add new files or edit existing ones.
5. **Commit and push** your changes:
   ```bash
   git add .
   git commit -m "Added [resource name] to [folder name]"
   git push origin feature/resource-name
   ```
6. **Create a Pull Request** from your fork to the main repository.

---

## 🙏 Contribution Tips
- Keep folder and file names clear and consistent.
- Prefer `.md` or `.txt` format for write-ups and `.cpp`, `.py`, etc., for code.
- Avoid uploading copyrighted material.
